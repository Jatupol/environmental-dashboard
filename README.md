# Environmental Excellence Dashboard — Portfolio Demo

> **Live demo:** https://jatupol.github.io/environmental-dashboard/

A working multi-plant sustainability performance dashboard built to demonstrate Scope 1/2/3 emissions tracking, water and waste KPIs, and SBTi-aligned target reporting — using methodology aligned with **GHG Protocol Corporate Standard**, **ISO 14064-1:2018**, and **TGO Carbon Footprint** standards.

This is a **portfolio demonstration** prepared by Jatupol Saramek for Environmental Excellence Manager / Sustainability Data Lead opportunities.

## ⚠️ Disclaimer

All data in this dashboard is **fictional** and generated for portfolio purposes. Plant locations approximate Coca-Cola Thailand (ThaiNamthip) operations but values do **not** reflect actual ThaiNamthip performance. The methodology, frameworks, and engineering patterns are real and production-grade.

## What's inside

- **6 plants** across 4 regions of Thailand (Central, Northeast, North, South)
- **24 months** of monthly environmental performance data
- **Scope 1, 2 (Market & Location-based), and 3** emissions inventory
- **Water-use ratio** and **waste diversion rate** tracking
- **Progress to 2030 target** (25% absolute reduction vs 2015 baseline, SBTi-aligned)
- **Data governance snapshot** with ISO 14064-3 verification readiness indicators

## Frameworks referenced

| Framework | Application |
|---|---|
| GHG Protocol Corporate Standard | Scope 1/2/3 inventory boundaries |
| GHG Protocol Scope 2 Guidance | Market vs Location-based dual reporting |
| ISO 14064-1:2018 | Operational control approach, audit trail design |
| TGO CFO methodology | Thailand-context Carbon Footprint for Organization |
| Thailand grid factor | 0.4999 kgCO₂eq/kWh (TGO 2023) |
| IPCC AR5 | GWP100 values for refrigerants |
| Ecoinvent 3.9 | Packaging materials (PET, glass, aluminum) |
| GRI 305 | Emissions reporting structure |
| CDP Climate | Disclosure framework alignment |
| SBTi | 2030 near-term target structure |

## Tech stack

- **Visualization:** HTML5, CSS3, Chart.js 4.4 (inlined for offline viewing)
- **Typography:** Manrope (display), IBM Plex Sans (body), JetBrains Mono (numerics)
- **Methodology equivalent in Power BI:** Star schema with Plants dimension, time-series fact tables, _Date table, 25+ DAX measures including time-intelligence and progress-to-target patterns
